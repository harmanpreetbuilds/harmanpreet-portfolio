## Featured Engineering Work

### Dervale — Enterprise AI Gateway Platform

My flagship engineering project.

Dervale is an AI infrastructure platform that provides applications with a controlled layer for accessing and operating multiple AI providers.

Instead of spreading provider-specific integrations, credentials, and AI logic throughout an application, Dervale centralizes them behind a unified gateway.

### Engineering Areas

- Java and Spring Boot backend
- REST API architecture
- PostgreSQL persistence
- Authentication and account recovery
- AI provider abstraction
- Provider credential management
- Developer API keys
- Multi-model execution
- Usage and token analytics
- AI cost visibility
- Conversation persistence
- React frontend
- Production-oriented architecture

The Dervale source repository is intentionally private.

Architecture, implementation details, and code walkthroughs can be discussed when required.

## Run Locally

Clone the repository:

```bash
git clone https://github.com/harmanpreetbuilds/harmanpreet-portfolio.git
cd harmanpreet-portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Run linting:

```bash
npm run lint
```

Create a production build:

```bash
npm run build
```
